# Receita & Afeto — Site de Receitas

Projeto acadêmico desenvolvido com HTML, CSS, JavaScript e Bootstrap 5, conforme o exercício de Interfaces Web I.

## Funcionalidades
- Página inicial com três receitas em destaque.
- Página individual de detalhes para cada receita.
- Ingredientes, modo de preparo, tempo, dificuldade e rendimento.
- Formulário para envio de comentários.
- Comentários salvos no `localStorage` do navegador (não há banco de dados/servidor).
- Layout responsivo.

## Como executar
1. Baixe ou clone este repositório.
2. Abra `index.html` no navegador. Para uma experiência melhor, use a extensão Live Server do VS Code.

## Tecnologias
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3 via CDN

As imagens e fontes são carregadas de serviços externos, portanto precisam de conexão com a internet.
